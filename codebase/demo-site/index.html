SOOCHAK / TEST SITE

Test a real push notification

A small test page for your Soochak workspace. Nothing is subscribed automatically.

1. Connect the site

  1. In your workspace, add this exact origin under Sites & Allowed Origins: Loading...
  2. Download the client JavaScript and worker handler for that site. Upload them beside this page as soochak-client.js and soochak-worker.js.
  3. Reload this page, then register the worker and subscribe below.

Use a dedicated HTTPS test site. An existing Service Worker is never replaced; to test an existing worker, integrate the downloaded handler into it first.
